# DevOps Portfolio — Kapongo José

Registo público da minha formação em DevOps (nov/2026 – jan/2027).

## Objetivo
Levar uma aplicação Laravel + Angular + MySQL de "corre no meu PC" até:
contentorizada, com CI/CD, segurança no pipeline, infraestrutura na AWS
como código (Terraform), configurada com Ansible, monitorizada
(Prometheus/Grafana/Loki) e com uma versão em Kubernetes.

## Roteiro
| Semana | Tema |
|---|---|
| S1 | Cultura DevOps, Linux, SSH |
| S2 | Bash, redes, Git |
| S3 | Docker e Docker Compose |
| S4 | Nginx/TLS e CI (GitHub Actions) |
| S5 | CD, DevSecOps, segredos, fundamentos de cloud |
| S6 | AWS e Terraform |
| S7 | Terraform em CI, Ansible, Prometheus/Grafana |
| S8 | Logs/alertas e Kubernetes |
| S9 | Kubernetes, GitOps, portefólio |

## Meta final
Certificação AWS Certified Cloud Practitioner (CLF-C02).
